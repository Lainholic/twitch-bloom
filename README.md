# Twitch Bloom & Junkyard

**Twitch Bloom & Junkyard**는 HTML5 2D Canvas 기반의 레트로 픽셀 아트 OBS 브라우저 오버레이입니다.  
트위치 실시간 채팅 명령어와 상호작용하여 방송 하단 테두리에 꽃을 피우고, 장난기 가득한 쓰레기를 투척하며, 환경을 청소하는 대화형 정원 & 쓰레기장 시스템입니다. 방송 종료 시에는 일일 활동과 MVP 시청자를 선정하는 **일일 결산 카드**를 고해상도 PNG로 생성합니다.

---

## 🌟 핵심 특징

1. **2D 레트로 픽셀 아트 캔버스 엔진 (Crisp Pixelated Mode)**
   - 1:1 도트 비율과 픽셀 보간 비활성화(`imageSmoothingEnabled = false`)로 깔끔하고 레트로한 감성 연출.
   - 4단계 식물 라이프사이클: 새싹(`sprout`) ➔ 장미(`rose`) ➔ 해바라기(`sunflower`) ➔ 황금꽃(`golden`).
   - 벽면과 천장을 따라 촘촘히 뻗어나는 2D 아이비 덩굴(Ivy Vines) 시스템 (물/햇빛 입력에 실시간 반응).
   - 찌그러진 캔, 피자, 바나나 껍질, 독버섯, 생선 가시, 커피컵, 배터리, 사과, 클로버, 포션 등 다양한 픽셀 소품.
   - 시청자 닉네임이 달린 픽셀 네임플레이트 부유.

2. **방송 실전 최적화 군중 제어 (High-Traffic Crowd Control)**
   - **웃음 쿨다운 및 전역 스로틀링**: 시청자별 1.5초 쿨다운 및 1초 전역 스로틀링 창을 두어, 수천 명이 동시에 `ㅋㅋㅋㅋ`를 쳐도 화면이 난장판이 되지 않고 절제된 미세 들썩임과 하트 파티클로 반응.
   - **쓰레기 전체 재발사 방지**: 바닥에 안착한 쓰레기 중 최대 4개만 가볍게 들썩이도록 물리 충격을 제한하여 스트리머 얼굴/게임 화면 시야 철저 보호.
   - **메모리 상한(LRU 500명 하드캡)**: 고유 시청자가 수천 명 유입되어도 500개 레코드로 자동 순환하여 24/7 장기 송출 시 메모리 누수 원천 차단.
   - **렌더 루프 GC 최적화**: 매 프레임 객체 할당을 제거한 정적 덩굴 설정으로 프레임 드랍(스터터링) 제로화.

3. **익명 원클릭 트위치 연동 (Zero-Config Twitch IRC)**
   - 복잡한 OAuth 토큰 없이 채널명만 입력하면 익명(`justinfan`) 읽기 전용 모드로 1초 만에 즉시 연동.
   - PING-PONG 킵얼라이브, 지수 백오프 자동 재연결, 500자 조기 차단 등 ReDoS 보안 완비.

4. **Web Audio 절차적 사운드 신디사이저**
   - 외부 음원/오디오 파일 의존도 0%. 물방울, 햇살 차임벨, 캔 둔탁음, 빗자루 쓸기, 웃음 퐁퐁 사운드 내장.

5. **일일 결산 카드 (Summary Card) & PNG 내보내기**
   - 오늘 하루 물주기, 햇빛, 청소, 쓰레기 투척 통계 집계.
   - 최고의 정원사(Top Gardener) 및 착한 트롤(Top Troll) MVP 선정.
   - 960x1280 고해상도 PNG 카드 즉시 다운로드 지원.

## 🎮 지원 명령어

| 명령어 | 한국어 별칭 | 동작 설명 |
| :--- | :--- | :--- |
| `!water` | `!물`, `!물주기`, `!plant`, `!심기` | 새싹을 심고 4단계로 성장시킵니다. (물방울 파티클) |
| `!sun` | `!햇빛`, `!해`, `!bloom`, `!개화` | 꽃의 개화를 촉진하고 덩굴에 햇살을 비춥니다. |
| `!trash` | `!쓰레기`, `!피자`, `!캔`, `!바나나`, `!물약` 등 | 공용 쓰레기장에 1/N 무작위 픽셀 쓰레기를 투척합니다. |
| `!clean` | `!청소`, `!빗자루` | 바닥에 쌓인 쓰레기를 쓸어내고 반짝이 가루를 날립니다. |
| `ㅋㅋㅋㅋ` | `lol`, `lul`, `lmao` | 화면의 꽃과 소품들이 부드럽게 들썩이며 하트가 피어납니다. (군중 제어 적용) |

## 🚀 빠른 실행 및 검증

### 1. 단위 테스트 실행 (12종 전체 검증)
```bash
npm test
# 또는
node --test tests/core.test.mjs
```
*(12/12 ALL PASS — IRC 파서, 군중 제어, LRU 메모리 상한, 1/N 쓰레기 풀, 스냅샷 불변성 완벽 검증)*

### 2. 로컬 웹 서버 실행
```bash
npm start
# 또는
python -m http.server 8089
```

### 3. 브라우저 접속 URL
- **일반 인터랙티브 모드**: `http://localhost:8089/`
- **자동 시연 모드 (15초 데모)**: `http://localhost:8089/?demo=1`
- **OBS 투명 오버레이 모드**: `http://localhost:8089/?obs=1&channel=스트리머아이디`
